Actividad 19 · Los primeros minutos cuentan

Adquisición forense en escenas del crimen digital

Introducción

En esta actividad se realizó la adquisición forense de información de un sistema Windows en funcionamiento, utilizando comandos de CMD y PowerShell, además de la herramienta NetUsers 1.23. Se recopilaron datos de usuarios, procesos, servicios, conexiones de red, registros y archivos para su posterior análisis.

Objetivo

Obtener y conservar información relevante del sistema operativo mediante comandos de adquisición forense, documentando los resultados para facilitar una investigación de seguridad informática.

Desarrollo

1. Fecha y hora del sistema

Problema: Identificar la fecha y hora configuradas en el equipo.

Get-Date -Format "dd/MM/yyyy HH:mm:ss"

2. Procesos en ejecución

Problema: Identificar los procesos activos y sus identificadores.

Get-Process | Select-Object ProcessName, Id, CPU, StartTime
tasklist /v

3. Servicios del sistema

Problema: Consultar los servicios y comparar CMD con PowerShell.

sc query type= service state= all
Get-Service | Select-Object Name, DisplayName, Status, StartType

4. Usuarios actualmente conectados

Problema: Identificar las cuentas que mantienen sesiones iniciadas.

.\NetUsers.exe /local

5. Historial de usuarios

Problema: Identificar las cuentas que iniciaron sesión anteriormente.

.\NetUsers.exe /history /local /verbose

6. Información de red

Problema: Obtener direcciones IP, MAC, DNS y configuración de red.

ipconfig /all
Get-NetIPConfiguration

7. Nombres NetBIOS

Problema: Identificar los nombres NetBIOS registrados y almacenados.

nbtstat -n
nbtstat -c

8. Conexiones establecidas

Problema: Obtener las conexiones de red, direcciones y puertos.

netstat -ano
Get-NetTCPConnection

9. Aplicaciones y puertos

Problema: Relacionar los procesos con sus conexiones y puertos.

$Conexiones = Get-NetTCPConnection

$Resultado = foreach ($Conexion in $Conexiones) {
    $Proceso = Get-Process -Id $Conexion.OwningProcess -ErrorAction SilentlyContinue

    [PSCustomObject]@{
        Aplicacion = $Proceso.ProcessName
        PID = $Conexion.OwningProcess
        IP_Local = $Conexion.LocalAddress
        Puerto_Local = $Conexion.LocalPort
        IP_Remota = $Conexion.RemoteAddress
        Puerto_Remoto = $Conexion.RemotePort
        Estado = $Conexion.State
    }
}

$Resultado | Format-Table -AutoSize

10. Dominios consultados

Problema: Identificar los dominios almacenados en la caché DNS.

ipconfig /displaydns

11. Direcciones IP y MAC

Problema: Consultar las asociaciones entre direcciones físicas y lógicas.

arp -a

12. Redes WiFi

Problema: Identificar los perfiles de redes inalámbricas almacenados.

netsh wlan show profiles
netsh wlan show profile name="NOMBRE_DE_LA_RED"

13. Historial de comandos

Problema: Recuperar los comandos almacenados en CMD y PowerShell.

doskey /history
Get-Content (Get-PSReadLineOption).HistorySavePath

14. Unidades mapeadas

Problema: Identificar las unidades de red conectadas.

net use
Get-SmbMapping

15. Recursos compartidos

Problema: Identificar las carpetas y recursos compartidos del equipo.

net share

16. Información del equipo

Problema: Obtener información del sistema operativo, hardware y usuario.

systeminfo
hostname
whoami /all
Get-ComputerInfo

17. Tareas programadas

Problema: Identificar las tareas automáticas configuradas en Windows.

schtasks /query /fo LIST /v
Get-ScheduledTask

18. Registros de eventos

Problema: Exportar los registros del sistema para su análisis posterior.

mkdir "%USERPROFILE%\Desktop\Logs_Actividad14"

wevtutil epl System "%USERPROFILE%\Desktop\Logs_Actividad14\System.evtx"

wevtutil epl Application "%USERPROFILE%\Desktop\Logs_Actividad14\Application.evtx"

wevtutil epl Security "%USERPROFILE%\Desktop\Logs_Actividad14\Security.evtx"

wevtutil epl Setup "%USERPROFILE%\Desktop\Logs_Actividad14\Setup.evtx"

19. Archivo HOSTS

Problema: Obtener una copia del archivo HOSTS y calcular su hash SHA-256.

$Hosts = "$env:SystemRoot\System32\drivers\etc\hosts"

Copy-Item $Hosts "$Evidencia\Resultados\19_hosts.txt"

Get-FileHash "$Evidencia\Resultados\19_hosts.txt" -Algorithm SHA256

20. Árbol de directorios y archivos

Problema: Obtener el listado de archivos y directorios según su fecha de creación.

dir C:\ /S /A /T:C > "%USERPROFILE%\Desktop\20_Arbol_Directorios.txt"

Conclusión

La actividad permitió conocer y aplicar diferentes herramientas de adquisición forense en Windows. Mediante los veinte procedimientos se obtuvo información relacionada con los usuarios, procesos, servicios, conexiones, registros y archivos del sistema. Esto permitió comprender la importancia de recopilar y conservar evidencia digital durante los primeros momentos de una investigación, facilitando su análisis y la identificación de posibles actividades sospechosas.
